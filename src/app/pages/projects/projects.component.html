Menú Digital Web

Plataforma web para restaurantes que permite mostrar menús digitales interactivos de forma organizada, accesible y atractiva.

Los restaurantes pueden presentar sus categorías y productos destacados, permitiendo a los usuarios explorar fácilmente el menú, filtrar por categoría, ver precios, descripciones e imágenes.

Incluye panel de administración para gestionar categorías e ítems del menú, todo en una experiencia moderna y responsiva.

  • React
  • Chakra UI
  • Firebase
  • TypeScript
  • Node.js
  • Express.js
  • Prisma
